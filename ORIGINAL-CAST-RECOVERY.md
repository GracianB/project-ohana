# OHANA · ORIGINAL CAST RECOVERY

This directory-level recovery preserves the original four-character cast from the early OHANA character build.

Source snapshot: `70b998be4d72e40aed673147bad210fa93c10de5`.

## Original cast

1. Lilo — Exploradora de la isla
2. Stitch — Experimento 626
3. Dragón de Milán — Guardián volcánico
4. Gato Kawaii — Explorador cósmico

The exact original definitions are stored in `characters/classic-originals.js` and the original vector renderer in `characters/classic-original-draw.js`.

This recovery is intentionally isolated from the current World 1 runtime so the closed 10-character release is not overwritten while the original designs remain preserved verbatim.
