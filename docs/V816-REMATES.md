Cuatro cambios comunes completan los 100.

1. El dibujado descarta posiciones y escalas no finitas.
2. La preparación mantiene brillo estable con movimiento reducido.
3. La marca de contacto conserva la dirección del golpe, incluso si el héroe gira después.
4. El cierre se desvanece según el tiempo que le queda al remate.
