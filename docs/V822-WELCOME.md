# Ohana 822 · Bienvenida a Isla Hoku

Tras cruzar el mar durante la carga, el jugador llega al embarcadero bajo el arco de Isla Hoku. La bienvenida usa una ilustración propia con encuadre vertical para móvil.

Jugar abre el selector. Continuar partida aparece con un guardado válido. Multijugador abre los dos modos existentes. Historia, Colección y Ajustes siguen disponibles desde la bienvenida. Los controles son botones nativos y admiten teclado, pantalla táctil y mando.

La portada se muestra sin repintar un lienzo continuamente. La ilustración se sirve como WebP y se guarda en la caché sin conexión.
